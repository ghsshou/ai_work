# 预览、区域任务与直接编辑

## 三种一级模式

- **预览**：操作 Deck 内的标签页、按钮和动画；
- **编辑**：文字内部保持文本光标，单击放置光标、按住拖选；红色选框边缘显示抓取手势，拖动边缘移动整个元素，拖动右下控制点缩放；从边缘选中整个元素后按 `Delete` / `Backspace` 删除，可随时撤销；
- **区域标记**：框选页面区域并写修改说明，积累后交给 Agent。

## 区域任务

1. 进入区域标记模式并框选目标区域。
2. 在旁侧输入具体说明，可附加文件或粘贴图片。
3. 继续跨页添加任务，或直接提交当前批次。
4. 点击“交给 Agent”后，本批任务进入处理中；之后新增任务留到下一批。
5. “待确认”表示目标不唯一，需要补充对象或位置，不是等待点击确认按钮。

任务面板把并行产生的工作明确分组：当前执行成员显示在“正在处理 · 批次 N”，此组暂时不能编辑或删除；处理期间新增的任务显示在“下一批 · 新标注”，仍可继续修改。若当前批次失败、取消或 Editor 重启，未完成成员进入“批次 N · 未完成”，可以单独重试，也可以由用户明确合并到下一批，系统不会自动混合两批任务。

## 临时切换

- 区域标记模式按住 `R`：临时预览，松开恢复标记；
- 编辑模式按住 `R`：临时区域标记，松开恢复编辑；
- `R` 按物理 `KeyR` 识别，中文输入法处于组合态时同样有效；真实文字输入框仍正常输入；
- 输入框和文字编辑状态中的 `R` 仍输入普通文字。

## 撤销和固化

人工动作与 Agent 的结构修改共用一条历史。未固化任务可以撤销和重做；固化后完成项仍可查看，但不再提供定点撤销。
