# 修改现有 Deck

## 适用场景

已经有 AICO-PPT 单文件 HTML，希望继续调整内容、格式、页面结构或动画。

## 操作步骤

1. 在 AICO-Harness 的 AICO-PPT 插件首页“修改已经写好的 deck”卡片右下角点击加号。
2. 使用系统文件选择器选择一份 HTML。
3. 确认 Agent 项目目录。本次手动选择优先于有效的历史设置；没有这些设置时，默认是 HTML 实际文件的直接父目录。点击“更改目录”会从当前已配置目录打开系统选择器；取消保留现配置，下次更改从最新目录打开。范围过宽时仍需确认，也可以改选更小的项目目录。
4. 打开编辑器，通过 Harness 左侧“新会话”的 AICO-PPT 项目选项创建关联会话。
5. 普通文字、移动、缩放和删除可在编辑模式直接操作；从红框边缘点选整个元素后按 `Delete` / `Backspace` 删除，复杂结构和动画交给左侧关联会话中的 Agent。
6. 使用撤销/重做核对修改，必要时在任务 drawer 查看未完成项。累计超过 10 条未固化修改时，顶栏会自动弹出一次轻量提醒；关闭后本轮不再重复打扰。
7. 点击提醒中的“查看并固化”或顶栏“固化修改”，通过验证后结果才写回真实 HTML。固化清空本轮历史后，下一轮修改会重新计数。

## 文件安全

Editor 会把真实 Deck 复制到 `.aico-ppt-editor` 中的托管工作副本。预览、自动保存和 Agent 修改都不会直接覆盖源文件。固化发生冲突或验证失败时会明确停止。

## 完成标志

顶栏没有未处理冲突，固化成功，并且重新打开源 HTML 可以看到最终结果。
