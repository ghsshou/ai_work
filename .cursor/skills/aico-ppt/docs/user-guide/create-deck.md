# 创建 Deck

## 适用场景

手头只有主题、文稿或参考材料，希望与 Agent 一起完成一份新 Deck。

## 操作步骤

1. 从 AICO-Harness 的 AICO-PPT 插件进入首页，在“从 0 开始创建一个新的 deck”卡片右下角点击加号。
2. 选择本次任务的独立项目目录。
3. 通过 Harness 左侧“新会话”中的 AICO-PPT 项目选项创建关联会话。
4. 在左侧关联会话中说明主题、听众、场景、预计页数和已有材料。
5. 与 Agent 依次确认需求、大纲和页面规划。左侧四个里程碑只显示文件状态，不是可点击步骤。
6. 合法 Deck 出现后，右侧画布自动展开；继续在同一 Harness 会话讨论修改。
7. 初版通过验证后进入微调 Editor，完成细节调整和固化。

## 重要约束

独立 Skill 用户直接在所用 Agent 中启动 `aico-ppt`，按同一流程完成讨论、模板选择、无窗口编辑和验证，不需要打开 Harness 或 Dev Shell。

- 主题、大纲和页面规划确认前，不直接修改模板；
- 封面必须第一、目录必须第二、感谢页必须最后；
- 结构修改由 Agent 通过 `scripts/edit-bundle.py` 操作托管工作副本；
- “固化修改”才会把结果发布回真实 Deck。

## 完成标志

最终 Deck 已发布，Editor 画布与真实文件一致，并通过 bundle、溢出和代表页截图验证。
