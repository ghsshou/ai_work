# 对话补充保留反馈任务身份，独立修改显式分离

Agent 根据对话追问、用户补充和当前反馈任务语义判断归属，工具不根据最近任务、任务数量或区域相交自动关联。当前工作项每步提供精简待办信息；`edit` 的 `taskId` 表达确切反馈身份，`taskRelation:new` 表达独立修改。仍有待办却两者都缺失时，工具拒绝写入并返回供 Agent 判断的信息，而不是强迫用户每次选择。补充的动作与源码事务均沿用原任务身份，Editor 原有提交、失败和批次结算规则保持不变。

这会让旧模型调用在遗漏归属时多一次只读纠正，换取避免“页面已改、原任务永久等待”与“新指令误关旧标注”。模型语义判断不能保证完全正确；多个合理候选需要澄清，工具参数不是用户意图的证明。已有无关联历史不会按页面内容猜测回填 taskId，原始 Deck 与会话不迁移。单元测试覆盖未选择、冲突和过期任务；真实编辑器测试覆盖独立新修改、失败写入、补充成功、原批次结算与下一批标注保留。
