# design-system.md — 设计系统（颜色 / 字体 / 字号 / 排版）

模板的视觉语言是一套完整体系：华为红品牌色 + 双字体 + 一套字号刻度 + 固定页结构。改页 / 加页前先过一遍本文，**加粗的都是铁律**。要贴近华为官方胶片的排版与文案风格（配色公式、标题句式、数字用法），另见 `huawei-style.md`。

## 1. 颜色：三色体系

| 色值 | 角色 | 用在哪 |
|---|---|---|
| `#b5333b` | **品牌红（主色）** | 标题强调、eyebrow、色块、导航高亮、真警示 |
| `#cf6b72` / `#e0a3a7` | 辅红 / 淡红 | 深色页上的红色强调与次要文字 |
| `#1565c0` | 强调蓝 | 「答案 / 是…」类点睛，一页最多一两处 |
| `#566472` | 灰蓝 | 与红形成对比的第二色：常规项、旧方案、次要徽标 |
| `#15171c` | 深底 | 小结 / 金句 / 黑板页整页背景 |
| `#fff` / `#fafafa` | 浅底 | 内容页背景，相邻页交替使用 |
| `#fbf4ee` / `#fdf0f1` | 米色框 | 类比 / 旁注 / 强调框底色 |
| `#585860` | 正文灰 | 正文、导语 |
| `#1a1a1c` | 深字 | 标题、加重文字 |

- **铁律：去花花绿绿。** 亮蓝、青、紫、琥珀、暖棕等杂色一律映射进「红 + 灰蓝 + 中性灰」三色体系。外部素材搬进来时先按此重新上色。
- **红色只给真正的警示 / 错误 / 本页重点**。中性框默认灰（细边 `#e7e7e7` / `#ececec`），别满页飘红。
- 真实数据截图**保留原生配色**，不强行改色。
- 整体换品牌色（红→你的主色）的全局映射方法见 `branding.md` 第 4 节。

## 2. 字体：只有两款

| 字体 | 用途 |
|---|---|
| `Noto Sans SC` | 标题、正文——**所有中文**（400/500/600/700 已内联打包） |
| `JetBrains Mono` | 数字、英文、代码、mono 小标签（eyebrow、徽标、编号） |

- **铁律：中文绝不能只挂 `JetBrains Mono`。** 它没有中文字形，中文会回退成一款细体、投影后看不清。凡是元素里可能出现中文，font-family 必须是（或回退到）`'Noto Sans SC',sans-serif`；要加粗就 `font-weight:700`，不要靠换字体。

## 3. 字号：一套刻度 + 21px 散文地板

- **唯一一套字号刻度**：正文区只用 `{13, 15, 17, 19, 21, 24, 27, 30}`（标题另算，≥34）。禁止 `10.2px` / `16.5px` 这类手调小数。
- **散文地板 = 21px（大屏讲课硬要求）**：所有「给听众读的散文」——正文、卡片正文、要点、callout、结论、题干、选项、答案、研讨条目——**最小 21px**。
- **图元字号按阅读任务判断**：坐标轴、紧凑表格、图内短标签可以低于 21px，但不是免检项；承担主要解释的段落仍按散文处理，不能靠放进表格 / SVG 或省略 `line-height` 豁免。先按目标观看尺寸目检，再调整字号、列宽或细节量；不要把整张图的文字机械放大。
- **截图里的关键文字必须可读**：平台界面、文章 / 课程封面可用来识别实物；若需要读者读出具体条目，就裁切放大或用原生文字列出，不能只留一个有文字但看不清的小缩略图。
- **保护不动**：eyebrow 固定 18px（`X.X · 中文 / ENGLISH`，`letter-spacing:.2em`）；题号与「填空 / 选择」徽标 chip；标题 ≥34 的已够大，再改只会溢出。
- **抬字号后溢出，优先原地压、不拆页**：① 被抬的散文收 `line-height`（1.55 → 约 1.35）；② 缩图——图是 `<img … max-height:Npx; object-fit:contain>` 时直接减 max-height 等比缩；③ 精简文字留核心。实在装不下再拆成两页。

## 4. 内容页结构与可选导语

画布 **1920×1080**，内容页 padding `56px 90px`（章扉页 / 问题页 `108px 130px`）。每页从上到下：

1. **eyebrow**：mono 小标签 `X.X · 中文 / ENGLISH`，18px，`letter-spacing:.2em`，品牌红；
2. **h3 大标题**：46px（密页可 40–42），`font-weight:600`，`#1a1a1c`；
3. **intro 导语默认省略**；只有主体成立前必须交代、且标题和正文尚未表达的背景 / 定义 / 范围才保留，21px，`#585860`。不重复概括标题，不写“本页将展示…”；
4. **主体**：`flex:1; min-height:0`——让主体吃满剩余高度且能收缩，这两个属性是版式不塌的关键。

### 4.1 小字取舍与来源去向

模板中的可选文字槽位不是必填项。对每段导语、角标、卡片补充说明与页尾小字做**删除测试**：删去后，读者对对象、关系、结论、行动和必要口径的理解是否改变？没有改变就删，不把它改得更小继续保留。

| 文字作用 | 处理 |
|---|---|
| 重复标题 / 正文、泛化收尾、作者自述（“复用的不只是代码…”“以下为建设建议…”）、版式说明、无业务含义的英文小标签 | 默认不生成；具体内容已由标题 / 主体表达时直接删，不补替代套话 |
| 内部材料文件名与页码、研究过程说明、反复出现的泛化免责句 | 来源位置实际记入 `<deck名>.plan.md` 的「事实与来源」；需交付给读者的详细推导放已确认的附录或可交付备注，不机械铺在每页页尾 |
| 数据单位、分母、前后比较基线、改变结论的版本 / 场景 / 时间范围，计划与已完成状态 | 与对应指标或结论就近呈现，按正常阅读层级排版；缺失会误导时必须保留，或收窄正文主张。不能用删小字把单场景结果变成普遍结论 |
| 引用署名、必须展示的来源 / 版权、品牌固定标识、有效章节导航、真实业务状态或图例 | 保留必要内容；来源用简短可辨认的署名 / 编号，详细定位留在来源记录。用户明确的引用要求优先 |

删去多余文字后，上移 / 扩展主体并重新分配表格列宽和图文空间，保留合理留白；不补新的导语、免责声明或结论条。**来源不能凭空消失**：使用备注前确认当前 HTML 与 PPTX 导出链路支持且实际写入；没有备注支持就保存在伴生 `.plan.md` 并随需交付，不口头声称“已移到备注”。

## 5. 页型语汇与统一卡片

全 deck 用同一套构件说话：**圆角卡片（radius 10–18）+ 细边 `#e7e7e7`/`#ececec` + 克制的小标签 + 强烈的 1–2 级字号对比**。纯英文、数字或代码标签可用 mono；标签含中文时仍用 `Noto Sans SC`。页型清单与活例见 `template-pages.md`，可粘贴骨架见 `page-snippets.md`。

内容卡片采用一套固定基线，不再逐页发明样式：

- **大卡片统一为白底、浅灰 1px 细边、14px 圆角**；同页与跨页都保持一致。表格、真实截图、SVG 图元和流程图内部节点不强行套大卡片样式。
- **同一组、同一层级、同一语义角色的兄弟卡片必须完全同构**：背景、边框、圆角、阴影、内边距以及标题 / 正文 / 标签的字体族、字号、字重、行距一致。不得为了构图、平衡颜色或制造所谓“重点”而给其中一张增加默认高亮。
- **卡片标题不得使用整条蓝 / 绿 / 红色底板**。标准大卡片标题统一使用 `Noto Sans SC`、21px、700、`line-height:1.35`，正文散文统一使用 `Noto Sans SC`、21px、400、`line-height:1.45`；同角色卡片不得各自改字体。标题默认 `#1a1a1c` 黑色，需要分隔时只加 `1px` 浅灰底边。
- 一张卡片只保留一层明确标题。删除不承载业务信息的胶囊、角标、英文缩写条和「结构 → 公式」「输入 / 引擎 / 输出」一类版式说明标签；业务状态、风险等级、真实单位等必要标签例外。
- 只有页面文案明确表达**选中、推荐、当前、风险或结论差异**时，才允许其中一张卡片使用品牌红文字、彩色底、特殊边框、阴影或额外字重；视觉差异必须能从卡片文字中读出原因。图表数据编码仍按图例使用颜色，不能拿来装饰普通卡片。

标准大卡片骨架：

```html
<div style="background:#fff;border:1px solid #d5d9de;border-radius:14px;overflow:hidden;display:flex;flex-direction:column;min-height:0;">
  <div style="padding:12px 16px;border-bottom:1px solid #e1e4e7;color:#1a1a1c;font-family:'Noto Sans SC',sans-serif;font-size:21px;font-weight:700;line-height:1.35;">卡片标题</div>
  <div style="padding:14px 16px;flex:1;min-height:0;color:#585860;font-family:'Noto Sans SC',sans-serif;font-size:21px;font-weight:400;line-height:1.45;">卡片内容</div>
</div>
```

**标准表格是独立语汇，不沿用卡片的浅灰边框**：表头统一品牌红 `#b5333b` + 白色居中粗体，表格全部边框为黑色，普通网格 1px、分组范围外框 3px；表体黑色，同级文字字号统一，按内容与投屏可读性选取（见 `artwork.md` 第 4 节）。默认三列宽度为 `15% / 19% / 66%`（分类 / 模块 / 说明），按实际阅读任务调整，主要空间给具体产物与证据，不为短分类词预留过宽列；列宽直接写到 `th` / `td`，不要只依赖 `colgroup`。表格用 `flex:1;min-height:0` 占满主体剩余高度；文字优先单行，空间不足时用 `white-space:normal;overflow-wrap:break-word` 自然换行，禁止用 `nowrap` 裁切。完整骨架见 `artwork.md` 第 4 节。

## 6. 审美硬要求（7 条）

1. **布局服务于有效内容**——用 `flex:1` 与网格分配主体空间，避免内容挤在顶部；删去低价值文字后可放大主要证据、调整列宽并保留合理留白，不能为了填满画布添加套话或把几行文字拉得过散。
2. **图 / 截图按列宽放大填满**——近方形图填满高框，截图 `width:100%`；小图缩在中间四周留白是最常见的败笔。
3. **强调框默认中性灰**，红只给文案已经说明的选中、推荐、当前、风险或结论差异（见第 1、5 节）；平等并列项不得单独高亮。
4. **结论放进对应内容栏内**，不要另起一条横贯整页底部的结论条。
5. **禁止无意义色块标题**——卡片标题无底色，黑字或品牌红字即可；章节横条、表格表头和真实状态条不属于卡片标题。
6. **禁止装饰性标签泛滥**——一个小标签不能回答「它承载了什么业务状态 / 单位 /分类」时就删除；不要用标签解释版式结构或操作方式。
7. **跨页统一优先于单页炫技**——改一页卡片风格时先审视整份 deck；同类型卡片必须同步圆角、边框、阴影、留白，以及标题 / 正文 / 标签的字体族、字号、字重和行距。

## 7. 1080 塞入铁律与验证法

- **任何一页的内容都必须塞进 1080 高**——section 是 `overflow:hidden`，超出就被无声裁掉，讲到那页才发现就晚了。
- 改完一批页就跑溢出检测（在 skill 根目录）：

```bash
node scripts/verify/measure_overflow.mjs my-deck.html --all
```

  退出码 0 = 全部通过；它同时报告 section 级溢出和内层 `overflow:hidden` 的裁切条目（后者只提示不判失败，逐条目检）。
- 手工在控制台量高度时的两个坑：① section 被 `height:100%` 锁死时 `scrollHeight == clientHeight`，量不出真实溢出——临时把 section 设 `height:auto` 再和 1080 比；② 独立预览环境若缺全局 `box-sizing:border-box`，先补 `*{box-sizing:border-box}` 再量，否则 padding 记账不一致。
- 密集多栏页除了 section 级，还要防「列内溢出」（某列底部超出但没顶到 section）——看 measure_overflow 的 nested clips 报告 + 截图目检。
