## Skills

Reusable skills live in `.cursor/skills/<name>/SKILL.md`. Before doing a matching task, read the skill's `SKILL.md` and follow it.

| Skill | Use when |
|---|---|
| [`pptx-layered-arch-diagram`](.cursor/skills/pptx-layered-arch-diagram/SKILL.md) | Drawing a top-down layered architecture / 框图 / 架构图 slide with nested boxes in PowerPoint (python-pptx), e.g. 立项 slides like `docs/design-simulator/` |

## Conventions

- Decks are generated by Python scripts next to them (`docs/<topic>/scripts/build_pptx*.py`); edit the script, then regenerate the `.pptx`.
- Versioned deliverables only grow: keep `_v1`, `_v2`, … files and add the next number instead of overwriting.
