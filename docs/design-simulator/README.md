# 设计态 AI 集群仿真器：负载引擎立项

面向 AI 集群整体系统设计（设计态，离线、无实时约束）的仿真器立项材料。底层 NPU / 内存存储 / 网络仿真已具备，本材料聚焦核心：**负载的画像、生成与导入**。

| [build_pptx.py](./scripts/build_pptx.py) | 生成脚本 |

## 主页结构

输入源 → **负载引擎** → 底层仿真内核（已具备） → 设计输出（DSE）

负载引擎六项核心技术：

1. **模型画像**：结构画像、并行策略展开为每 rank 算子图 + 通信、算子代价模型、MoE 路由 / KV 等动态特征
2. **到达与请求分布**：突发到达（MMPP/Hawkes）、日周期、多租户；输入/输出长度联合分布、前缀复用、Agent 会话；训练作业规模与故障
3. **Trace 拟合与外推**：多源对齐与依赖重建、迭代压缩、分布拟合检验、千卡→十万卡扩展、跨硬件重定向
4. **负载数据工厂**：采集→清洗脱敏→特征化→建模→合成→保真校验→版本入库，产出场景化标准负载库
5. **统一负载 IR 与多保真导入**：硬件无关执行图（兼容 Chakra ET），L0 解析 / L1 算子图 / L2 包级
6. **闭环校准**：小规模实测对标、误差回灌；分布保真 + 效用保真
